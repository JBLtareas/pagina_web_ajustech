# Ajustech

Sitio web con **React + Vite** en el frontend y **Node + Express** en el backend.

## Desarrollo

```bash
npm install
npm run dev
```

- Frontend: [http://localhost:5173](http://localhost:5173)
- API: [http://localhost:4000](http://localhost:4000)

## Producción

```bash
npm run build
npm start
```

El servidor sirve la API y la carpeta `dist` en el puerto `4000`.

## Video de fondo

Coloca `videodefondo.webm` en `public/` para el fondo del modo oscuro.
